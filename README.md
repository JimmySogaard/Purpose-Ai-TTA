# Purpose-AI-TTA: Adaptive AI War Room 🚀

**Chaos-to-Purpose Elevation System**

An adaptive AI war room that transforms chaos into purposeful action through the TTA loop (Tanker/Thoughts, Følelser/Feelings, Handling/Actions). Built with a give-back ethos: **Power to Folket** (Power to the People).

## 🌟 Core Features

### 1. **TTA Loop** - Chaos to Purpose Transformation
- **Tanker (Thoughts)**: Process raw input and chaotic ideas
- **Følelser (Feelings)**: Emotional and intuitive processing
- **Handling (Actions)**: Generate purposeful, aligned actions

### 2. **Hybrid AI Integration**
Seamlessly integrate multiple AI providers:
- 🤖 **Grok**: Advanced reasoning and analysis
- 🧠 **Kimi**: Contextual understanding
- 💡 **Claude**: Ethical and nuanced responses

Switch between providers or get consensus from all three!

### 3. **369 Capital Management**
Inspired by Nikola Tesla's sacred numbers:
- **3 (30%)**: Innovation & Growth - Moonshot projects
- **6 (60%)**: Stability & Operations - Sustainable infrastructure  
- **9 (10%)**: Give-back to Folket - Community empowerment

### 4. **Moonshot Simulations**
- Monte Carlo simulations for high-impact scenarios
- Risk assessment and probability calculations
- Best/worst case analysis
- Evidence-based decision making

### 5. **Fri Tale (Free Speech)**
Open dialogue interface where every voice matters. Direct communication with AI systems in a judgment-free space.

### 6. **Security & Privacy**
- Encrypted data storage
- Secure API key management
- Private repository for secure development
- GDPR-compliant design

## 🚀 Quick Start

### Installation

1. **Clone the repository**:
```bash
git clone https://github.com/JimmySogaard/Purpose-Ai-TTA.git
cd Purpose-Ai-TTA
```

2. **Install dependencies**:
```bash
pip install -r requirements.txt
```

3. **Configure environment**:
```bash
cp .env.example .env
# Edit .env with your API keys
```

4. **Run the War Room**:
```bash
python main.py
```

## 💻 Usage

### War Room Commands

Once started, you can use these commands:

- `tta` - Execute TTA Loop (Thoughts → Feelings → Actions)
- `fri-tale` - Free speech mode for open dialogue
- `capital` - View 369 capital management system
- `moonshot` - Run moonshot simulations
- `ai` - Manage AI providers (switch between Grok/Kimi/Claude)
- `history` - View session history
- `help` - Show all commands
- `exit` - Exit war room

## 🎲 Moonshot Simulation Example

```python
from purpose_ai.moonshot_sim import MoonshotSimulator, MoonshotScenario

sim = MoonshotSimulator()

# Create custom scenario
scenario = MoonshotScenario(
    name="Open Source Innovation Hub",
    description="Community-driven tech innovation space",
    risk_level=0.4,
    potential_impact=0.8,
    resources_required={'capital': 100000, 'team': 5},
    timeline_months=12
)

# Run simulation
result = sim.simulate_scenario(scenario)
print(f"Success probability: {result.success_probability:.1%}")
print(f"Recommendation: {result.recommendation}")
```
